> 100+ company job-listing destinations for review. A URL is only considered verified after the automated link check passes and the page is confirmed to expose openings or a public ATS job board. HTTP success alone does not prove scraper integration or that openings are currently available.

- Company destinations: **130**
- Superhuman uses `/company/careers/jobs`, not the parent `/company/careers` landing page.
- Run status is provided by the `job-listing-link-check` GitHub Actions workflow added with this document. A small number of official job portals may block automated HTTP clients; those require browser confirmation rather than treating 403/429 alone as proof of a dead link.

## Validation policy

- Redirects are followed and final HTTP status is recorded.
- A destination must return a successful response and show job-listing/role content; a generic marketing page is not an acceptable target.
- JavaScript-rendered sites that cannot be verified by the lightweight HTTP check must be reviewed manually before being marked verified.
- These URL checks do not substitute for end-to-end scraper tests that confirm actual job records are extracted. Some official sites block automated clients; the script only treats such cases as passing when that exact URL is listed in the browser-verified allowlist.
